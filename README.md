## About

**PyraMid** is a personal collection of Python programs, built layer by layer —
starting from simple scripts and steadily climbing toward more advanced projects.
Think of it as a pyramid of practice: a solid base of fundamentals, with each
level adding more complexity.

## What's Inside

| Level | Description |
|-------|-------------|
| Basic | Simple, beginner-friendly scripts |
| Intermediate | Logic-driven programs and mini utilities |
| Advanced | Larger, more complex projects |

## Structure

PyraMid/
├── basic/
├── intermediate/
├── advanced/
└── README.md

## Getting Started

Clone the repository and run any script directly:

```bash
git clone https://github.com/<your-username>/PyraMid.git
cd PyraMid
python <folder>/<script_name>.py
```

## Purpose

This repository serves as a personal learning log and reference stack —
a place to track progress, revisit old solutions, and keep building on
Python fundamentals over time.
